# GTM Material Plan — Self-Hosted Deployment

## Goal
Create concise, sales-ready Markdown collateral in `docs/gtm/` that positions AuditFlow AI as a self-hosted compliance automation platform where customer data stays in their infrastructure and we install our code to start working with their infra and data.

## Target Audience
- **Primary**: VP Engineering, Head of Security, Director of Compliance at 50–500 employee mid-market companies in regulated industries
- **Secondary**: External auditors and audit partners

## Files to Create

| File | Purpose | Key Content |
|------|---------|-------------|
| `docs/gtm/readme.md` | Overview / index of all GTM materials | One-paragraph positioning, links to other docs |
| `docs/gtm/problem-statement.md` | The pain point | 200–400 hours per audit cycle; manual evidence collection; continuous compliance drift; vendor risk |
| `docs/gtm/how-it-works.md` | Solution mechanism | 5-step agent pipeline (ingest → map → collect evidence → gap analysis → report) |
| `docs/gtm/usp.md` | Unique selling proposition | Self-hosted in customer infra, data never leaves their environment, zero data residency risk, install-and-run |
| `docs/gtm/deployment.md` | Plug-and-play deployment | Docker / Helm chart install, connects to existing data sources (GDrive, Jira, GitHub, AWS Config), runs in customer VPC, output in their S3/bucket |

## Key Messages to Enforce Across All Docs
1. **Data residency is non-negotiable**: Customer data never leaves their infrastructure.
2. **Install, don't import**: We deploy code into their environment; they don't send data to us.
3. **AI agents, not consultants**: Automated policy-to-control mapping, evidence collection, and gap analysis.
4. **Audit-ready output**: Human-reviewed PDF packages + structured JSON exports.
5. **SOC 2 Type II beachhead**: Proven on SOC 2; extensible to ISO 27001, HIPAA, PCI-DSS.

## Out of Scope
- Pricing tables
- Competitive battle cards vs named competitors
- Web/landing page components
- Sales script / email templates
