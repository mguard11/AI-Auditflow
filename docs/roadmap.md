# Product Roadmap

## MVP — Months 1–6

**Goal**: 10 design partners paying $0–$5K/mo. Prove the core compliance evidence workflow.

### Features
- [ ] Policy document upload (PDF, DOCX, Markdown, Google Docs)
- [ ] Automatic mapping to SOC 2 Type II control framework
- [ ] ISO 27001 framework support
- [ ] Evidence request automation (Google Drive, Notion, Jira, GitHub)
- [ ] Gap report generation with remediation suggestions
- [ ] Audit-ready package export (PDF + structured JSON)
- [ ] Basic dashboard (org settings, audit runs, download reports)
- [ ] Simple RBAC (admin, auditor, viewer)

### Success Metrics
- 10 design partners onboarded
- Avg. 80%+ evidence collection automation rate
- NPS > 40 from compliance officers

---

## Platform — Months 7–18

**Goal**: $2M ARR, 80–120 customers. Expand framework support and add continuous monitoring.

### Features
- [ ] Continuous compliance monitoring (watch AWS Config, GCP, Azure for drift)
- [ ] Vendor risk assessment agent (auto-score third-party SOC 2 reports)
- [ ] Policy update agent (when regulation changes, flag affected controls)
- [ ] HIPAA framework support
- [ ] PCI-DSS framework support
- [ ] GDPR / CCPA framework support
- [ ] Slack integration for compliance alerts
- [ ] Multi-user collaboration (comments, assignments, review workflows)
- [ ] API access for enterprise self-integration
- [ ] SSO / SAML

### Success Metrics
- $2M ARR
- 130%+ NRR
- < 12 month CAC payback

---

## Expansion — Year 2+

**Goal**: $8M ARR. Launch adjacent vertical agent packs.

### Agent Packs
- [ ] **HR & Onboarding Agent**: I-9, background checks, policy acknowledgments
- [ ] **Contract Review Agent**: Redline, clause extraction, obligation tracking
- [ ] **Finance Close Agent**: Reconciliation, variance commentary, board decks
- [ ] **Healthcare Credentialing Pack**
- [ ] **Logistics Safety Pack**
- [ ] **Fintech BSA/AML Pack**

### Platform
- [ ] White-label for accounting firm partners
- [ ] Auditor portal (direct audit firm access to evidence packages)
- [ ] Mobile app (iOS/Android) for on-the-go compliance review
- [ ] Custom framework builder (bring your own control set)
